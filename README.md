# ElevenTV 2.0

面向 Android TV 的局域网媒体播放器，支持 SMB / WebDAV 双协议接入 NAS，本地扫描、自动刮削、海报墙浏览与断点续播。

---

## 功能简介

- **双协议 NAS 接入**：SMB 走自研连接池（SMBJ），WebDAV 走 Media3 HTTP 栈，一套界面切换；服务器配置持久化，密码 Keystore 加密。
- **本地媒体库**：递归扫描（8 层目录），按文件名解析季/集/年份，同名剧自动归并（集号不相交 / 年份差 ≤1 才合并，不误拼两部同名剧）。
- **自动刮削**：TMDB + Fanart.tv 补全海报、背景、简介；中文标题优先；支持单条 / 全库 / 强制重刮。
- **海报墙浏览**：瀑布流混排 2:3 / 3:4 / 1:1.15 三种比例，分类筛选 + 排序，3 米视距 6 列布局。
- **播放核心**：MediaCodec 硬解为主，可切软解；512KB 预读缓冲解决高码率卡顿；断点续播；自动连播；字幕（文本 + PGS/VOBSUB 位图）6 档字号。
- **品牌启动**：系统窗口 → Compose 动画两段衔接，逐字母淡入 + 收尾音效（可关），1 秒内完成不拖首页挂载。

## 使用说明

### 安装

1. 用 `adb install ElevenTV-x.x.x-webdav-release.apk` 安装到电视盒子（需开启 USB 调试）。
2. 或拷到 U 盘，在盒子文件管理器里直接安装。
3. 首次运行进入**引导页**：填服务器名、IP、端口、共享名、用户名密码。

### 添加服务器

- 设置 → 服务器 → 添加：协议选 SMB 或 WebDAV，填主机 / 端口 / 共享 / 凭证，点「测试」验证连通。
- 测试通过后选择根目录，保存即加入媒体源列表。

### 扫描与刮削

- 添加服务器后自动扫描；首页顶部「重新扫描」手动触发。
- 刮削默认开启，扫描完成后自动补齐元数据；在设置里可关闭或强制重刮。

### 遥控器操作

| 按键 | 作用 |
|------|------|
| 方向键 | 浏览焦点 |
| OK / 回车 | 选择 / 播放 |
| 返回 | 退回上一级 |
| 上（焦点在卡片时） | 直达筛选 chips |

### 关键设置

- **记忆播放进度**：默认开，下次打开从上次位置继续（快看完的从头）。
- **自动播放下一集**：默认开。
- **字幕字号**：0.85× ~ 2.6× 六档，TV 上 3 米外仍可读。
- **启动音效**：默认开，与启动动画对齐的短提示音，可关。
